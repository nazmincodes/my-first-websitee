# 🍽️ Nazmin's Restaurant Website

এটি **Nazmin's Restaurant**-এর একটি প্রাথমিক ওয়েবসাইট যা শুধুমাত্র **HTML5** ব্যবহার করে তৈরি করা হয়েছে। এই প্রজেক্টের মাধ্যমে রেস্তোরাঁর খাবারের তালিকা (Menu), অর্ডার ফর্ম, পেমент অপশন এবং যোগাযোগের মাধ্যম প্রদর্শন করা হয়েছে।

🌐 **Live Demo:** [Nazmin's Restaurant](https://nazmincodes.github.io/my-first-websitee/)  
💻 **GitHub Repository:** [my-first-websitee](https://github.com/nazmincodes/my-first-websitee)

## ✨ মেইন ফিচারসমূহ (Key Features)

* **নেভিগেশন বার:** ওয়েবসাইটের বিভিন্ন সেকশনে দ্রুত নেভিগেট করার সুবিধা।
* **সম্পর্কে তথ্য (About Section):** রেস্তোরাঁ সম্পর্কে সংক্ষিপ্ত ধারণা।
* **খাবারের তালিকা (Menu Section):**
  * মূল খাবার (Burger, Pizza, Pasta) ছবির সাথে টেবিল আকারে ছাড়সহ (Discount) মূল্য তালিকা।
  * ডেজার্ট আইটেম (Ice Cream, Cake, Cookies)।
  * স্টার্টার আইটেম (Chicken Wings, Spring Rolls, Garlic Bread)।
* **অনলাইন অর্ডার ফর্ম (Order Form):** গ্রাহকের নাম, ইমেইল এবং পছন্দনীয় খাবার নির্বাচনের অপশন।
* **পেমেন্ট অপশন:** Cash on delivery, bKash, Nagad এবং Card payment সমর্থিত পদ্ধতিসমূহ।
* **যোগাযোগ (Contact Info):** রেস্তোরাঁর ঠিকানা, ফোন নম্বর এবং ইমেইল অ্যাড্রেস।
